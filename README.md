1. Project Overview

Urban Thread is a fictional local streetwear business website developed for the WEDE5020 Portfolio of Evidence (POE).

The website provides information about the business, displays its products and prices, and allows visitors to make product enquiries and prepare general contact messages.

The project focuses on modern, affordable streetwear for teenagers, college students, and young adults between the ages of 16 and 30.

The website was developed in stages. Part 1 focused on planning and creating the initial website structure. Part 2 focused on CSS styling and responsive design. Part 3 focuses on JavaScript functionality, interactive features, form validation, search engine optimisation (SEO), testing, and final improvements.

2. Goals and Objectives

The main goals of the website are to:

* Create an online presence for Urban Thread.
* Display products, descriptions, and prices.
* Provide information about the business.
* Allow customers to make product enquiries.
* Provide contact information and a contact form.
* Create a simple and user-friendly website.
* Support different screen sizes, including desktop, tablet, and mobile.
* Provide clear navigation between all website pages.
* Improve website functionality through JavaScript.
* Apply SEO techniques to improve the organisation and discoverability of the website.
* Improve the user experience through interactive features and form validation.

3. Website Pages

The website contains five main HTML pages.

Technical limitation: The current website is a static front-end project.
